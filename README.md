# TURTLE-SNAKE

## About The Project

An exploratory Python project with Turtle: a very basic Snake game. The snake grows and speeds up each time it eats food, and the game ends when it hits a wall or itself.

### Built With

- Python
- Turtle graphics

## Getting Started

### Prerequisites

- Python 3 with Tkinter (needed by Turtle)

### Running

```sh
python main.py
```

## Usage

Use the arrow keys to steer the snake.
